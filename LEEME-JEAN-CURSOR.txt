MAIA — ZIP 1: Proyecto completo para Cursor
============================================

Qué es: monorepo maia-platform (app + componentes + reglas Cursor).

Cómo abrir:
1. Descomprimir esta carpeta
2. Abrir la carpeta en Cursor (File → Open Folder)
3. En terminal:
   cd maia-platform
   npm install
   npm run dev
4. Navegador: http://localhost:3000

Estructura:
- apps/web/          → pantallas MAIA (Screening workbench)
- packages/ui/       → componentes Shadcn base
- .cursor/rules/     → reglas de diseño MAIA

URL publicada (misma app): https://maia-ux-web.vercel.app
